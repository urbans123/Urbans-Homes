# Setup & Run

## Instalación

```bash
npm install
npm run dev
```

Se abre en http://localhost:3000

## Requisitos

- Node.js v16+
- npm (incluido con Node)

## Comandos

```bash
npm run dev      # Dev server
npm run build    # Build producción (dist/)
npm run preview  # Preview
```

## ¿Problemas?

```bash
# Cache limpio
npm cache clean --force

# Si el puerto está en uso, npm automaticamente usa otro
npm run dev

# Recarga el CSS
Ctrl + F5
```

## Stack

- React 18
- React Router v6
- Vite 5
- CSS3
