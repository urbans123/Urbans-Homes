# Urban Homes - React App

Plataforma inmobiliaria con gestión de propiedades en Medellín.

## 🚀 Instalación

```bash
npm install
npm run dev
```

Abre http://localhost:3000

## 📁 Estructura

```
src/
├── components/   # 5 componentes reutilizables
├── pages/        # 6 páginas (Home, Propiedades, Contacto, Nosotros, Login, Carrito)
├── styles/       # CSS modular por página
├── App.jsx       # Router
└── main.jsx      # Entry point
```

## 📦 Tech Stack

- React 18
- React Router v6
- Vite
- CSS3

## ✨ Features

✅ Hero slider automático (5.5s)
✅ Contadores animados
✅ Filtros de propiedades
✅ Modal de reservas
✅ Formulario de contacto
✅ Responsive (Mobile, Tablet, Desktop)
✅ SPA sin recargas

## 📄 Rutas

| Ruta         | Página              |
| ------------ | ------------------- |
| /            | Home - Landing page |
| /propiedades | Listado con filtros |
| /contacto    | Formulario          |
| /nosotros    | About + Equipo      |
| /login       | Autenticación       |
| /carrito     | Reservas            |
